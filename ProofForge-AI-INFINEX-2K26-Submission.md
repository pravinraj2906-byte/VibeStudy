# ProofForge AI — INFINEX 2K26 submission

## Project title

ProofForge AI — Evidence-First Engineering for AI-Built Software

## Problem statement and solution

AI can generate software faster than developers can understand or verify it. This creates fragile code, hidden security risks, and weak ownership. ProofForge maps an uploaded repository, explains its architecture through a friendly personal mentor, remembers each learner's goals, identifies security findings, guides repairs, and verifies outcomes with deterministic scanners and tests. Model guidance and engineering evidence remain clearly separated.

## Technology stack

React 19, TypeScript, Vite, Tailwind CSS, Three.js and React Three Fiber power the responsive frontend and interactive architecture views. FastAPI, Python, SQLAlchemy, Alembic and PostgreSQL power the API, authentication, projects and per-user mentor memory. Gemini provides source-grounded teaching. AST and heuristic scanners plus Pytest provide deterministic evidence. Docker supports deployment.

## Key proof points

- Account-free judge prototype that demonstrates the full product story.
- Personal learning memory scoped to each authenticated user and project.
- Explainable 100-point Repository Evidence Score with visible deductions.
- Responsive workflow and system diagrams plus an optional interactive 3D architecture view.
- Scanner benchmark: 10 labeled fixtures, 5 true positives, 5 true negatives, 0 false positives and 0 false negatives. Precision, recall and accuracy are 100% within this fixture set.
- Honest model boundary: Gemini teaches; static analysis and tests verify.
- Failure-safe behavior: repository facts remain available when Gemini is unavailable, browser memory temporarily backs up account memory when the API is unavailable, and code execution fails closed when an isolated worker is absent.
